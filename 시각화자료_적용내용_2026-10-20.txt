시각화 자료 탭 적용 내용 / 2026-10-20

사용 주소
http://localhost:8000/#/visualizations

사용 순서
1. 화면을 새로고침하고 왼쪽에서 질문할 기업을 선택합니다.
2. 문답에서 “우리 회사 최근 매출 추이를 알려줘”처럼 질문합니다.
   원하는 사업, 기간, 순매출/공급가액/VAT 등의 기준을 지정하면 비교 범위가 명확해집니다.
3. 답변을 받은 같은 대화에서 “이 내용을 꺾은선그래프로 보여줘”라고 요청합니다.
4. 답변 아래 “시각화 자료 보기”를 누릅니다. 왼쪽 “시각화 자료”에서도 열 수 있습니다.
5. 원래 값은 그래프 아래 표에, 원 답변과 항목별 근거는 접기/펼치기에 표시됩니다.
6. 다른 표현으로 보고 싶으면 화면의 표현 방식 선택을 바꾸거나 같은 대화에서 다시 요청합니다.
   화면에서 바꾼 표현 선택 자체는 임시이며, 새 자료로 저장하려면 문답에서 다시 요청합니다.

지원 범위
표, 막대, 꺾은선, 영역, 원형, 도넛, 산점도, 히트맵, 일정표, 순서가 있는 절차도.
모든 종류의 임의 시각화를 생성하는 기능은 아닙니다.
지도, 간트, 레이더, 네트워크, 3D 등은 현재 표로 대체하고 이유를 안내합니다.
일정표는 날짜/업무를 나열하는 방식이며, 기간 길이를 그리는 간트 차트는 아닙니다.
절차도는 확인된 순서만 나열합니다. 복잡한 분기나 의존관계를 새로 추론하지 않습니다.
최대 32행, 8열입니다. 데이터가 많으면 기간이나 사업을 나눠 요청해 주세요.

값이 부족할 때
숫자가 없거나 단위가 서로 다르면 표로 표시합니다.
한 시점의 값만 있으면 매출 “추이”를 만들지 않고 표로 표시합니다.
자료에 없는 값은 0으로 채우거나 예상값으로 만들어 넣지 않습니다.
원형/도넛의 비중은 표시된 구성값 합계가 분모입니다. 회사 전체 비중인지 원 답변의 범위를 확인해 주세요.
기존 항목별 근거 검사가 없는 옛 대화, 근거 없는 일반 지식 답변은 새로 질문해야 합니다.
시각화 변환 실패와 자료 부족은 안내를 구분하며, 이미 받은 답변은 유지됩니다.

변경한 코드
src/psm/visualizations.py: 요청 감지, 구조화 변환, 인용/셀/숫자/단위/축 검사, 비용 정산, 저장
src/psm/api.py: 문답과 시각화 연결, 조회/삭제 API, 사용자·기업·선택 문서 범위 확인
src/psm/schema.sql: visualizations 테이블 추가 (기존 테이블의 내용 변경 없음)
src/psm/conversations.py: 자료 링크 복원, 시각화 안내를 사실 질문의 맥락에서 제외
web/js/main.js: 시각화 자료 탭 추가
web/js/views/visualizations.js: 목록, 원 대화 이동, 삭제, 파일 저장
web/js/visualization-renderer.js: 고정 SVG/표 렌더러, CSV 수식 실행 방지
web/js/chat-messages.js / views/chat.js: 생성 결과와 이동 버튼
web/styles.css: 새 탭 스타일

저장과 비용
원 문서 1,000개, 기존 Dify 색인, 기존 사업 지표는 재색인/수정하지 않습니다.
포트는 8000입니다. 시각화 자료는 기존 로컬 SQLite DB의 별도 테이블에 저장합니다.
사용자·기업별로 조회합니다. 새로고침해도 저장 내용이 남습니다.
문서가 변경되어도 저장된 그래프가 자동 갱신되지는 않습니다. 다시 질문하고 생성해야 합니다.
단순한 “이 답변을 그래프로” 요청은 Dify를 재검색하지 않습니다.
새 기간·사업을 질문하면 기존 검색과 항목별 근거 검사 후 시각화합니다.
시각화 구조화 시 현재 OpenAI 모델에 확인된 답변을 보내는 호출이 추가되어 API 비용이 발생합니다.
이번 개발 점검에서는 실제 OpenAI/Dify 검색 호출로 답변 품질 평가를 진행하지 않았습니다.

개발 검증 결과
- 외부 API 통신을 차단한 Python 검사: 108건 통과
- JavaScript 화면/렌더링 검사: 46건 통과
- Ruff 및 git diff --check 통과
- 가상 값으로 SVG/표 렌더링과 실제 빈 자료 화면 확인
- Dify 인증 정상, 사용 가능한 기존 문서 1,000개, 포트 8000 확인
- 원본 1,000개 파일 해시 및 documents/assets/asset_index_links/business_metrics/kpi_breakdowns 내용 일치 확인
위 수치는 자동 기능 검사 통과 건수이며 AI 실제 답변 정답률이 아닙니다.

직접 테스트할 때 확인할 내용
- 처음 질문과 시각화의 기업·사업·기간·매출 종류가 같은지
- 표의 수치·단위가 답변의 확인된 수치와 같은지
- 부가세, 감액, 누계/당월, 내부 비용 한도 등 해석 조건이 보존되는지
- “이 내용을 표로/그래프로”가 직전 답변을 사용하는지
- 새 기간을 지정하면 이전 기간 값이 재사용되지 않는지
- 일부만 확인된 답변은 확인된 값만 나타나는지
- 회사 전환 시 다른 회사 자료가 섞이지 않는지
- 새로고침 후 저장 자료와 원 대화 링크가 유지되는지

원문 일치/타입 검사는 의미적인 정답을 보장하는 성능 점수가 아닙니다.
실제 문서 질문에 대한 품질 테스트와 KPI 평가는 사용자가 직접 진행합니다.
변경 내용은 현재 로컬 feature/beomsu-project-labels 작업 폴더에 있으며 자동으로 GitHub에 업로드하지 않았습니다.
