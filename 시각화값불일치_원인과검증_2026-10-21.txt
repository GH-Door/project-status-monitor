‘시각화 값과 답변 원문이 일치하지 않음’ 원인 조사
작성일: 2026-10-21

1. 확인한 실제 사례
기업: 은유크리에이티브 (회사 ID 5)
대화 ID: 30
첫 질문: 현재 우리 기업의 최근 매출 추이해줘
후속 질문: 이 내용을 토대로 시각화 자료 탭에 그래프로 나타내 줄 수 있을까?
메시지 165: 프로젝트별 8월·9월 금액을 답변.
메시지 167: 시각화 값과 답변 원문이 일치하지 않아 저장하지 않았다는 오류.

이번 후속 질문은 ‘시각화 요청’으로 정상 분류됐습니다.
앞선 긴 요청의 분류 오류와 달리, 이번에는 변환 결과를 검증하는 단계에서 차단됐습니다.
이 오류가 ‘문서에 숫자가 없다’거나 ‘금액이 반드시 틀렸다’는 뜻은 아닙니다.
기존 코드는 열 개수 오류, 출처 연결 오류, 셀의 문자열 불일치를 같은 문장으로 안내했습니다.

2. 실제 처리 경로
매출 질문 → 문서 검색 → 모델이 자연어 답변 생성
→ 시각화 요청 → 모델이 답변을 표 형태로 변환
→ 서버가 표 구조·셀 문자열·출처·수치·단위를 검사
→ 검사 실패로 저장 중단.

이전 수정에서 서버 계산을 적용한 매출 질문 표현의 범위가 좁았습니다.
‘우리 회사’와 달리 이번의 ‘현재 우리 기업 ... 추이해줘’는 해당 경로에서 빠졌습니다.
저장된 visualization_data가 비어 있어 모델을 통한 표 변환이 실행됐습니다.
따라서 시각화 키워드 인식만 고쳐서는 이 문제까지 해결되지 않았습니다.

3. 동일 입력 재현에서 확인한 오류
저장된 답변 165를 그대로 사용해 시각화 변환을 한 번 재실행했습니다.

가. 표 구조 불일치
열 이름: [프로젝트, 기간, 매출] → 3개
첫 행 값: [1, 라디온모빌, 2026년 8월, 44,800,000원] → 4개
모델이 출처 번호로 보이는 ‘1’을 셀에도 넣었습니다.
수치 축 번호도 3으로 지정해, 0부터 세는 3개 열의 범위를 벗어났습니다.
이 상태로 저장하면 열과 값의 대응을 신뢰할 수 없어 차단해야 합니다.

나. 기간 표현의 문자열 불일치
원 답변: ‘2026년 8월과 9월’
변환 셀: ‘2026년 9월’
뜻은 이어서 읽을 수 있지만 ‘2026년 9월’이라는 연속 문자열은 원 답변에 없습니다.
기존 검사는 원문에서 정확히 복사했는지를 확인하므로 이 표현도 통과하지 못합니다.
이번 재현에서 금액 셀 자체는 답변에 있는 금액이었습니다.

중요한 조사 한계:
최초 실패 당시 생성된 표는 저장되지 않았습니다.
위 내용은 동일한 입력으로 새로 재현한 결과이며 최초 출력과 완전히 같다고 확정할 수 없습니다.
실제 실패 기록으로 확정 가능한 것은 시각화 변환 후의 대조 단계에서 차단됐다는 점입니다.

4. 별도로 확인한 원 답변의 오류
원 답변은 ‘각 9월 매출에는 감액 전표가 반영되어 있다’고 했지만,
제시한 금액은 원장에 있는 감액 전 청구 공급가액이었습니다.

예: 라디온모빌, 004_매출정산원장_라이트.md
9월 청구 공급가액: 35,200,000원
9월 감액: 2,400,000원
감액 반영 순공급가액: 32,800,000원

35,200,000원을 감액 반영 금액이라고 설명한 것은 잘못됐습니다.
답변의 숫자를 그래프에 그대로 복사하는 검사만으로는 이런 의미상의 오류를 잡을 수 없습니다.
‘답변과 그래프가 같은가’와 ‘답변이 원장을 정확히 설명하는가’는 별도 검증입니다.
